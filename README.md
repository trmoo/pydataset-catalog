# PyDataset 데이터 도감

파이썬 패키지 **PyDataset** 이 담고 있는 연습용 데이터 **757개**를
주제별로 찾아보는 수업용 웹앱입니다.

> 「막대그래프를 연습해야 하는데 쓸 만한 데이터가 없다」
> 「iris 말고 다른 건 없나요?」
> — 이럴 때 씁니다.

## 학생·교사가 쓰는 법

1. `dist/index.html` 파일 하나만 있으면 됩니다. **더블클릭하면 바로 열립니다.**
   인터넷도, 설치도 필요 없습니다.
2. 위쪽 탭 네 개 — 🗂️ 주제별 보기 / 🔎 찾기 / 📊 그래프로 고르기 / 📖 안내
3. 데이터셋 카드를 누르면 컬럼 목록과 **맷플롯립 예제 코드**가 나옵니다. 복사해서 코랩에 붙이면 됩니다.

데이터를 실제로 불러 보려면 코랩에서 한 번만:

```bash
pip install pydataset
```

```python
from pydataset import data
df = data('iris')
print(df.head())
```

## 데이터셋 하나를 누르면

* 한국어 한 줄 제목과 영어 원제
* 행 × 열, 숫자 열·범주 열 개수, 빠진 값, 행 이름이 있는지
* **컬럼 표** — 이름 · 종류(숫자/범주/글자/참거짓) · 다른 값의 개수 · 빠진 값
* `data('iris')` 불러오기 코드 (복사 단추)
* **그릴 수 있는 그래프마다 맷플롯립 예제 코드** (복사 단추)
* 경고 — 부를 수 없는 이름인지, 파일이 잘못 담겼는지, 비어 있는지

## ⚠ 수업 전에 알아 두면 좋은 것

앱을 만들며 PyDataset 0.2.0 을 뜯어보다 찾은 것들입니다. 「안내」 탭에 자세히 적어 두었습니다.

1. **이름이 겹치는 것이 30쌍** 있고 쌍마다 한쪽은 부를 수 없습니다.
   `data('lung')` 은 `survival` 것이고 `KMsurv::lung` 은 어떻게 해도 안 나옵니다.
   그래서 데이터셋은 757개인데 부를 수 있는 이름은 **727개**뿐입니다.
2. **파일이 잘못 담긴 것이 13개** 있습니다. `MASS/housing.csv` 를 열면
   R 의 `MASS::housing`(72행 5열)이 아니라 `multgee::housing`(1448행 4열)이 나옵니다.
3. **비어 있는 것이 2개** 있습니다 (`Zelig/friendship`, `Zelig/sna.ex` — 행이 0개).
4. **`data('datasets')`** 를 부르면 자료가 아니라 757행짜리 **목록표**가 나옵니다.

## 개발

```bash
npm install          # 의존성 설치
npm start            # 개발 서버
npm run build        # dist/index.html 한 파일로 빌드
npm test             # 시험 117가지
npm run check:syntax # 문법 · 저작권 · 대화상자 · 화면 수명 검사
npm run data         # 자료 다시 만들기 (pydataset·pandas 가 있어야 한다)
```

`npm run data` 는 `pip install pydataset` 이 되어 있어야 합니다.
파이썬에서 한 번 `data()` 를 부르면 PyDataset 이 홈 폴더(`~/.pydataset`)에
자료를 풀어 놓는데, `tools/build_data.py` 가 그것을 읽어
`tools/catalog_ko.py`(한국어 제목·분류)와 합쳐 `src/data/catalog.js` 를 만듭니다.
